# CodeStates
**코드스테이츠에서 진행한 과학기술정보통신부 주관 K-Digital Training 프론트엔드 과정 중 실습한 과제/미니 프로젝트 레포지토리입니다.**
- 추가 설명:  
  본 저장소는 내일배움카드 기반의 KDT 과정에서 학습한 내용을 바탕으로, HTML/CSS 기초부터 JavaScript, React, Express, JSON Server, Spring 기반 API 설계까지 다양한 기술 스택을 활용한 프로젝트들을 포함하고 있습니다.  
  각 폴더는 독립된 과제 또는 미니 프로젝트 단위로 구성되어 있으며, 실습 목적에 따라 기능 중심의 구현을 진행했습니다.
---

## 📁 폴더별 실습 과제 소개
| 폴더명 | 설명 |
|--------|------|
| `CodeStates-BE-Assign1-AgoraStates-Server/` | Express 기반의 RESTful API 서버로, 토론 데이터를 추가·조회·삭제하는 백엔드 실습 프로젝트 |
| `CodeStates-BE-Project1-ExpressServer-BasicSetup/` | Express.js를 활용해 API 서버를 구축하고, 미들웨어 설정과 라우팅을 실습한 백엔드 과제 |
| `CodeStates-FE-Assign1-AgoraStates/` | JavaScript로 구현한 동적인 토론 포럼 페이지. 질문 제출, 페이지네이션 기능 포함 |
| `CodeStates-FE-Assign2-Proxy-BookCRUDApp/` | 프록시 서버를 활용하여 백엔드와 통신하며 도서 정보를 CRUD 처리하는 React 애플리케이션 |
| `CodeStates-FE-Project1-CartPage-BasicLayout/` | HTML과 CSS로 장바구니 UI의 기본 레이아웃을 구성한 정적 페이지 프로젝트 |
| `CodeStates-FE-Project2-TodoApp-RESTfulAPI/` | React와 RESTful API를 연동하여 할 일을 추가/삭제/수정/완료 처리하는 투두 앱 |
| `CodeStates-FE-Project3-TodoApp-JsonServer/` | json-server를 활용하여 투두리스트 항목을 관리하는 간단한 CRUD 애플리케이션 |
| `CodeStates-FS-Assign1-AgoraStates-DiscussionApp/` | React와 Express를 활용한 풀스택 토론 게시판 앱. 클라이언트 UI + 서버 API 통합 실습 포함 |
---

## 🛠️ 사용 기술 스택
- **Frontend**: HTML, CSS, JavaScript, React, Vite
- **Backend**: Node.js, Express.js, JSON Server
- **Fullstack**: React + Express 기반 애플리케이션
- **기타**: RESTful API, Proxy 설정, CRUD 구현 등
---

## 📌 학습 목적
- 프론트엔드와 백엔드의 구조를 이해하고, 요청-응답 흐름을 코드로 구현  
- 다양한 방식의 CRUD 기능을 직접 구현하면서 React와 서버 통신 경험을 축적  
- 팀 개발을 위한 기초 역량 확보 및 기능 개발 중심의 실전 연습
